## Resultado

Se creó [`docs/diseno_experiencia.md`](../../diseno_experiencia.md) y se implementó su recorrido local en la ruta inicial. La experiencia incluye mapa, filtros de etapa, selección de nodo, controles, restablecimiento de vista, detalle y navegación textual equivalente.

## Entregables implementados

- `src/components/Explorer.tsx`: mapa interactivo con React Flow y disposición automática mediante Dagre.
- `src/data/portfolio.ts`: nodos, conexiones, etapas, capacidades y proyectos compartidos por el mapa y el HTML.
- `src/pages/index.astro`: introducción, fallback HTML y montaje del explorador.
- `src/styles/global.css`: estados de foco, disposición responsive, detalle móvil y estilos del mapa.
- `src/layouts/BaseLayout.astro`: estructura de navegación, idioma, metadatos y enlace para saltar al contenido.

## Criterios de cierre

- Los controles tienen texto visible y foco identificable.
- La selección muestra descripción y enlace directo.
- Las conexiones se explican mediante etiquetas y texto.
- El detalle queda debajo del mapa en el flujo responsive.
- El contenido esencial y los enlaces siguen presentes en HTML.
- El diseño no depende de color para comunicar una relación.
- No se añadieron afirmaciones, fechas, métricas, roles ni resultados al contenido aprobado.
