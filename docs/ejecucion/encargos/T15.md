# Encargo T15 — Publicar y fijar mantenimiento

**Estado:** en curso
**Dependencias:** T14 y D14
**Responsable:** Integrador

## Decisión vigente

La primera publicación usará GitHub Pages sobre el repositorio `RamaReid.github.io`, con URL prevista `https://ramareid.github.io/`. El dominio propio queda fuera de esta primera publicación.

## Preparación local realizada

- Astro usa `https://ramareid.github.io` como URL del sitio.
- Los canonical y JSON-LD usan la misma URL centralizada.
- `.github/workflows/deploy-pages.yml` instala dependencias, ejecuta `check` y `build`, y publica `dist/` mediante GitHub Pages.
- No se incorporan `referencias_privadas/` ni los originales al artefacto.

## Falta para cerrar

1. Crear o confirmar el repositorio público `RamaReid.github.io`.
2. Vincularlo como remoto del repositorio local.
3. Hacer push de `main` con autorización expresa.
4. Configurar GitHub Pages si la cuenta lo solicita.
5. Comprobar la ejecución de Actions, la URL pública, rutas, imágenes, canonical y navegación.
6. Registrar mantenimiento y cerrar T15.

No se debe marcar T15 como completa antes de comprobar el despliegue real.
