**Estado:** completada
**Dependencias:** T08, T09 y revisión del perfil GitHub
**Responsable:** Contenido / Desarrollo / Integrador

## Objetivo

Incorporar al portfolio una selección verificable de trabajos de programación web e IA a partir del perfil público de `RamaReid`, manteniendo separadas las implementaciones observables, las declaraciones de autoría y las interpretaciones editoriales.

## Fuente y alcance

- Perfil público: [github.com/RamaReid](https://github.com/RamaReid).
- Repositorios copiados para revisión local: `referencias_privadas/04_GitHub_RamaReid/repos/`.
- Matriz privada: `referencias_privadas/04_GitHub_RamaReid/matriz_programacion_ia.md`.
- El caso Productoria permanece en su ficha independiente y se enlaza como trabajo de IA.
- Los repositorios vacíos, insuficientemente documentados y los datos de demostración quedan fuera de las afirmaciones públicas.

## Entregable

Una ficha pública `/casos/programacion-interfaces/`, cinco capacidades conectadas al mapa y a la navegación textual, matriz privada de repositorios y registro de límites editoriales.

## Criterios de cierre

1. La ruta funciona con HTML estático y contiene metadatos coherentes.
2. El mapa, la lista textual, la página del caso y las capacidades usan las mismas relaciones.
3. Cada afirmación técnica pública puede localizarse en un repositorio y commit revisados.
4. La autoría se presenta como declaración curricular cuando no puede inferirse del commit individual.
5. No se publican secretos, datos personales, conversaciones privadas, métricas sin fuente ni placeholders como obras reales.
6. `npm.cmd run check`, `npm.cmd run build`, rutas HTTP locales y `git diff --check` pasan.
7. El informe distingue cambio local, commit, push, despliegue y URL comprobada.

## Traspaso

El ejecutor devuelve los archivos modificados y las comprobaciones realizadas. El integrador actualiza el tablero y cierra T11. No se realiza push ni despliegue durante este encargo.
