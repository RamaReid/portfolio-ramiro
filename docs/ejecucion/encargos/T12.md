## Objetivo

Definir e implementar un canal de contacto y un perfil público que sean legibles sin JavaScript, estén autorizados y tengan un destino comprobado.

## Decisión aplicada

El perfil individual de GitHub proporcionado por Ramiro, [github.com/RamaReid](https://github.com/RamaReid), funciona como perfil profesional y canal de contacto. El enlace respondió HTTP 200 el 2026-09-06.

No se incorpora correo, teléfono ni formulario porque no existe en el alcance vigente un dato o servicio autorizado para publicarlo.

## Entregable

Ruta `/contacto/` con el perfil y canal aprobado, enlace directo a GitHub, contexto profesional, JSON-LD coherente y límite explícito sobre los canales no definidos.

## Criterios de cierre

1. El canal publicado fue autorizado y su destino respondió correctamente.
2. La ruta contiene HTML esencial y puede leerse sin JavaScript.
3. El perfil tiene contexto y enlace directo.
4. No se inventan ni agregan datos personales de contacto.
5. Los metadatos y JSON-LD coinciden con el contenido visible.
6. `npm.cmd run check`, `npm.cmd run build`, la ruta HTTP local y `git diff --check` pasan.
7. El informe diferencia cambio local, commit, push, despliegue y URL comprobada.
