## Objetivo

Definir el contrato editorial y de datos que permita alimentar con una misma fuente el mapa interactivo, la navegación textual en HTML, las páginas de casos, la trayectoria temporal y los metadatos.

## Contexto que debe recibir el modelo

Leer antes de modificar:

- `AGENTS.md`;
- `docs/ejecucion/INICIO.md`;
- `docs/ejecucion/DECISIONES.md`;
- `docs/alcance_inicial.md`;
- `docs/ejecucion/TAREAS.md`, ficha T05;
- `docs/ejecucion/entregas/T01.md`, `T01-revision.md`, `T02.md` y `T02-revision.md`.

La arquitectura debe respetar que el contenido esencial exista en HTML, sea legible sin JavaScript, tenga URLs directas y pueda interpretarse por buscadores. T03 aporta el relato autorizado y T04 aporta el catálogo textual, el manifiesto de 102 imágenes y las rutas de evidencias. T05 debe definir la estructura sin inventar afirmaciones del caso ni incorporar originales privados.

## Encargo

Proponer en `docs/arquitectura_contenido.md` un contrato común que describa, como mínimo:

- tipos de página y propósito de cada una;
- modelo de caso, capacidad, etapa, evidencia, conexión y evento temporal;
- estado explícito de caso sin evidencias visuales, sin romper la navegación textual;
- campos obligatorios, opcionales y estados editoriales;
- relación entre una afirmación, su fuente privada, autorización y texto público;
- slugs, URLs directas y enlaces descriptivos;
- cómo el mapa y la navegación textual consumen la misma información;
- fallback HTML para selección, detalle y lectura sin JavaScript;
- requisitos de metadatos y datos estructurados, incluyendo la regla de coincidencia con el contenido visible;
- reglas para no publicar materiales privados;
- ejemplos abstractos o mínimos que no agreguen datos biográficos no aprobados.

Separar decisiones confirmadas, propuestas de arquitectura y cuestiones que todavía requieran decisión. No fijar contacto, dominio, alojamiento, analítica, diseño visual ni versiones de bibliotecas. React dentro de Astro, React Flow y Dagre son la dirección técnica registrada para T07/T08, pero este encargo define contenido y conexiones; no valida ni implementa esas bibliotecas.

## Entrega y comprobaciones

Devolver el documento y un informe siguiendo `docs/ejecucion/ENTREGA.md`. Comprobar realmente:

1. el mapa, la navegación textual y las páginas usan el mismo contrato;
2. una ruta directa permite llegar al caso y, cuando existan, a sus evidencias autorizadas;
3. la ausencia de JavaScript no elimina el contenido esencial;
4. los campos de fuente y autorización no se confunden con contenido público;
5. JSON-LD y metadatos quedan ligados al contenido visible;
6. el contrato no introduce casos, cifras, roles, fechas o resultados no aprobados;
7. el informe separa cambio local, commit, push, despliegue y URL.
