## Criterios de cierre

1. El mapa permite seleccionar nodos y muestra sus conexiones explicadas.
2. La página inicial contiene una navegación textual con las mismas relaciones.
3. El caso, los proyectos y las evidencias tienen enlaces directos.
4. El recorrido tiene controles de teclado, foco visible, desplazamiento, zoom y restablecimiento.
5. En móvil el detalle queda debajo del mapa.
6. Sin JavaScript se puede leer el caso, las conexiones y acceder a los proyectos.
7. Las páginas verificadas devuelven HTTP 200 y mantienen metadatos coherentes.
8. No se incorporan materiales privados ni afirmaciones nuevas.
