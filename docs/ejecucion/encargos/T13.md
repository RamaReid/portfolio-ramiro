## Objetivo

Comprobar la versión local completa en contenido, HTML, enlaces, metadatos, accesibilidad estructural, responsive, privacidad, compilación y peso de salida.

## Comprobaciones

1. `npm.cmd run check` sin errores, advertencias ni avisos.
2. `npm.cmd run build` con todas las rutas estáticas generadas.
3. Previsualización local con HTTP 200 para cada `index.html` generado.
4. Verificación de enlaces internos, HTML base, contenido esencial y JSON-LD.
5. Revisión de teclado y accesibilidad estructural en componentes y HTML: idioma, skip link, foco visible, etiquetas y detalle textual.
6. Revisión de media queries, detalle móvil y reducción de movimiento.
7. Búsqueda de materiales privados, archivos `.env` y datos no destinados al frontend.
8. Registro del peso de salida y de cualquier riesgo que deba resolver T14/T15.

## Criterio de cierre

El informe debe registrar resultados reales, incidencias y límites. Un riesgo de rendimiento debe quedar visible y no convertirse en una afirmación de optimización inexistente. T13 puede cerrarse cuando el sitio sea comprobable localmente y los riesgos queden asignados al siguiente paquete.
