# Programación, interfaces y sistemas visuales

**Tipo:** caso adicional · repositorios públicos

**Fuente editorial:** [perfil público de RamaReid en GitHub](https://github.com/RamaReid)

## Alcance

Esta ficha reúne implementaciones de programación web e interfaces que pueden revisarse en repositorios públicos. El conjunto incluye una aplicación de catálogo con React y TypeScript, una experiencia editorial con rutas y transiciones, sistemas de carga con SVG, CSS y JavaScript, y prototipos estáticos para sitios de arquitectura.

La ficha describe estructuras, componentes y decisiones observables en el código. No presenta métricas, clientes, publicaciones, despliegues ni resultados de negocio que no estén documentados en las fuentes revisadas.

## Piezas seleccionadas

### OMMI · catálogo interactivo

El repositorio contiene una aplicación Vite con React y TypeScript. La experiencia se organiza alrededor de un `CatalogStage`, líneas de catálogo, un modelo de datos de fragancias y rutas para distintas vistas del catálogo. El estado de la línea y de la fragancia activa coordina el escenario, la botella y el rack de tubos.

Fuente: [commit revisado de OMMI](https://github.com/RamaReid/OMMI/tree/da3ac2ab774b05481af4c3891b7fb35b7265b6f8).

### Seamless Navigation · escenas y recorridos

El repositorio contiene una aplicación React con TypeScript, rutas, escenas, transiciones, navegación de proyectos y componentes para una experiencia editorial de arquitectura. El historial revisado incluye commits de distintos autores; por eso esta ficha presenta el repositorio como trabajo aportado al conjunto y no atribuye cada commit individual a una sola persona.

Fuente: [commit revisado de seamless-navigation](https://github.com/RamaReid/seamless-navigation/tree/69858047a2a902ed63565f83afa493f95f6ac8d2).

### Loaders y movimiento de marca

`Loader-GD`, `LoaderRespaldo` y `WebGDArquitecturaDisenoConstruccion` contienen variantes relacionadas de loaders con SVG, máscaras, variables CSS, keyframes, ciclos y eventos de transición. Se presentan como una misma línea de exploración de movimiento frontend, sin convertir cada variante en un caso independiente.

Fuentes: [Loader-GD](https://github.com/RamaReid/Loader-GD/tree/edb5d8fbf9dfecbb10f488ddacc32b6885b50836), [LoaderRespaldo](https://github.com/RamaReid/LoaderRespaldo/tree/c5837d7f9cca931b707bd0b841a1c5e920bdb096) y [WebGDArquitecturaDisenoConstruccion](https://github.com/RamaReid/WebGDArquitecturaDisenoConstruccion/tree/18d78131dd824405d2d30cd9a4e34dd872363745).

### Revista y navegación con PageFlip

`carruselHTML` documenta una revista interactiva construida con HTML, CSS y JavaScript alrededor de PageFlip. La pieza sirve para mostrar una interacción editorial concreta y su adaptación responsive; no se presenta como evidencia de publicación externa.

Fuente: [commit revisado de carruselHTML](https://github.com/RamaReid/carruselHTML/tree/af7d70eff6963d17ba39d61b91b90840f2be03e8).

### Prototipos web para arquitectura

`gd-arquitectura` y `GD-Arquitectura-Diseno-y-Construccion` muestran dos enfoques de sitio: una base con Next.js, TypeScript, Tailwind y componentes editoriales, y una versión estática con HTML, JavaScript y mapa. El segundo repositorio contiene contenido de demostración; esta ficha solo toma la implementación de interfaz y mantiene fuera los nombres, ubicaciones y proyectos usados como placeholder.

Fuentes: [gd-arquitectura](https://github.com/RamaReid/gd-arquitectura/tree/edaead93ddd1bf73af7eaa5357855e2e92ca5d66) y [GD-Arquitectura-Diseno-y-Construccion](https://github.com/RamaReid/GD-Arquitectura-Diseno-y-Construccion/tree/d2d8079321abfe29a410f82cb2c4b433ba42619c).
